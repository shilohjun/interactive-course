# 周一演示脚本（2–3 分钟）

目标：让王老师在一分半内看懂「播放器 + 课包 + 探索 + 提问」，剩下时间看可核验路径。

## 准备

- 打开 `http://101.33.230.189/course/`（未部署时用本机 `http://localhost:5174/course/`）。
- 音量 70%；浏览器缩放 100%；关闭无关标签。
- 若要演示续播，先播 20 秒再刷新；否则清掉 localStorage 从头开始。
- 桌面默认打开 Transcript；想先看全板，点顶部 Transcript 收起。移动端默认收起先看板。

## 镜头

| 时间 | 画面 | 动作/台词 |

## 兜底

- 视频加载失败：页面会显示 “Video unavailable”，幻灯片和字幕仍可演示；提前在本地留一份 mp4。
- 步步解打不开：用配置里的深链直接打开一次，说明是外部服务；不要在演示里改它。
- 网络慢：所有静态资源同源，视频 28 MB；提前打开一次缓存。

- 不承诺区域级高亮、学习报告回写、MAT3007 已完成。
